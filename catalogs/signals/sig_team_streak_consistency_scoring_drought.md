# sig_team_streak_consistency_scoring_drought

## Purpose

Flags goalless runs of three or more matches, a negative-form and under-markets signal.

## Tactical And Statistical Logic

- Trigger: Team fails to score in >= 3 consecutive matches (this match included).
- A goalless match is `goals_for = 0`. The sequence is every finished match of the team in `fotmob_silver.match` (all loaded competitions), ordered by `match_date` then `match_id`. One row is emitted for each match where the running streak length is >= 3. Only loaded matches count, so a short history can shorten a real streak.
- Similarity note: Closest: `sig_team_shooting_goals_wasteful_box_presence` and `sig_team_shooting_goals_blank_range` (single match). Different grain. No overlap.
